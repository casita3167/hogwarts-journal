# 霍格華茲不可說的祕密

包含年度分類、左右閱覽、五篇可編輯社刊、人物圖片、內容編輯器與完整網頁匯出。圖片已內嵌在 index.html，不需要另外設定圖片路徑。

## 上傳與部署

1. 解壓縮 ZIP。
2. 將 index.html、README.md 與 .nojekyll 放在 casita3167/hogwarts-journal 的根目錄；不要上傳 ZIP 本身，也不要多包一層資料夾。
3. 儲存庫 Settings → Pages → Source 選 Deploy from a branch。
4. Branch 選 main，資料夾選 / (root)，按 Save。

## 編輯與更新

按「製作新頁」撰寫內容；按「更新內容」管理既有頁面。新增預設 1984 年，既有五篇為 1982 年。
刊名固定：霍格華茲不可說的祕密。
頁尾固定：學生特刊 ｜ 歡迎投稿 ｜ 永銘社訓。

草稿與修改儲存在目前瀏覽器，不會自動同步到 GitHub，也不會自動更新其他讀者看到的內容。
完成修改後，按「匯出完整網頁」，將下載的檔案重新命名成 index.html，再上傳取代儲存庫中的 index.html。
若曾在其他網址編輯過未匯出的內容，請先從原網址匯出；不同網址的瀏覽器儲存內容不共用。
